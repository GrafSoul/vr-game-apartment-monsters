# Квартирные монстры — MR-шутер для Quest 3

Твари прорываются из стен твоей комнаты. Работает в браузере Meta Quest 3 через WebXR (React Three Fiber + `@react-three/xr`).

## Как играть

- Пистолет в правой руке, курок стреляет.
- Мелкие летуны выходят из стен. Сначала только глазастые шары, с 3-го уровня к ним добавляются крылатые черепа (быстрее, пикируют сверху), с 4-го — горящие черепа: зависают, разгораются и таранят, взрываясь при ударе; их сбивает один выстрел. С каждым появлением открывается несколько разломов, но тварь выскакивает только из одного; треск разлома слышно с той стороны, где он открылся.
- Перед броском тварь замирает и дрожит — это шанс выстрелить. Долетевший бросок кусает: минус одна броня из пяти.
- Уровень: убить 6 тварей, дальше на 2 больше. Прочность тварей: 1 попадание на 1-м уровне, 2 на 2-м, 3 с 3-го.
- Каждый 3-й уровень заканчивается боссом: Three-Head Baby Mutant выходит из стены, подкрадывается и прыгает.
- Броня кончилась — уровень начинается заново.
- На левом предплечье лежит панель: уровень, броня, счётчик тварей или здоровье босса, кнопки «Пауза», «Заново», «Тени», «Свет −», «Свет +», «Окклюзия». Посмотри на панель — пистолет сменится указкой; наведи на кнопку и нажми курок.

Без разметки комнаты (Space Setup) стены ставятся вокруг игрока на расстоянии трёх метров.

Баланс уровней — в `src/game/rules.ts`.

## Запуск на шлеме

1. Подключи Mac и Quest 3 к одной сети Wi-Fi.
2. Запусти сервер:

   ```bash
   npm run dev
   ```

3. В браузере шлема открой `https://<IP Mac>:5173` (IP показан в выводе сервера в строке Network).
4. На предупреждении о сертификате нажми «Дополнительно», затем «Перейти».
5. Нажми «Войти в MR» и разреши доступ к пространству.

## Запуск на шлеме по USB-кабелю

Если шлем не видит Mac по Wi-Fi (другая подсеть, изоляция клиентов на роутере).

1. Включи на шлеме режим разработчика (приложение Meta Horizon → устройство → настройки гарнитуры).
2. Подключи шлем к Mac кабелем USB-C с передачей данных и разреши отладку по USB в шлеме.
3. Запусти сервер командой `npm run dev`.
4. Пробрось порт:

   ```bash
   adb reverse tcp:5173 tcp:5173
   ```

5. В браузере шлема открой `https://localhost:5173`.

## Запуск на Mac с эмулятором

```bash
npm run dev:local
```

Открой `http://localhost:5174`. Эмулятор Quest 3 (IWER) подставляет синтетическую гостиную с диваном.

## Модели

- Исходник: `assets/source/hunter-models.blend` (текстуры упакованы).
- Экспорт из Blender: `assets/export/*.glb`.
- Облегчённые модели для шлема: `public/models/*.glb`, пересобираются командой `npm run models`.
